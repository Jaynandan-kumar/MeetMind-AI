# MeetMind AI

MeetMind AI is a full-stack real-time video conferencing, collaboration, and cloud development platform powered by WebRTC, Socket.IO, Clerk Authentication, and VertexAI Studio.

## Features
- **High Quality Video Calls**: Peer-to-peer encrypted video and audio conferencing with WebRTC.
- **In-Meeting Chat**: Real-time messaging with participant status and unread badges.
- **Participants Management**: Live participant tracking and host controls.
- **Integrated Cloud IDE (VertexAI)**: In-meeting side-by-side collaborative code editor and AI coding agent.
- **Flexible Subscription Plans**: Clerk-powered pricing and upgrade tiers.

## Project Structure
- `/client`: MeetMind React + Vite frontend application.
- `/server`: MeetMind Express + Socket.IO WebRTC signaling backend.
- `/vertexAI`: Cloud IDE frontend and backend microservices suite.
